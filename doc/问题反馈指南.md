# 问题反馈指南（LyLaunch）

遇到问题时，一份好的反馈能大幅缩短定位时间。请通过项目仓库的 **Issues** 提交。

---

## 提交前先确认

- 搜索一下已有 Issues，避免重复提交。
- 确认是最新版本（设置 → 关于 显示的版本号）。

---

## 反馈三件套

请尽量提供以下三项：

1. **版本信息**：设置 → 关于 中显示的版本号。
2. **复现步骤**：点了什么 → 期望什么 → 实际看到什么（截图 / 录屏更好）。
3. **日志**：`%LocalAppData%\LyLaunch\crash.log`
   （把这一行粘到文件资源管理器地址栏回车即可打开目录；没有该文件通常说明不是崩溃，而是界面逻辑问题）。

```
- Windows 版本：

```

## 常见问题

1. **SmartScreen / 杀软误报**：未签名的 exe 可能被系统或杀软拦截，属个人项目常见情况。
   可按需选择「更多信息 → 仍要运行」，或仅对单个文件加白名单（不建议关闭整个实时防护）。
2. **桌面被 OneDrive 重定向**：「桌面净化」收纳后文件在 `桌面\桌面净化`，同步可能触发上传，使用前请先确认。
3. **收纳会真的移动文件**：使用前请备份重要文件，可用「恢复原状」移回。
4. **卸载前先恢复**：先点「恢复原状」再卸载，否则文件会留在「桌面净化」文件夹里（不会丢，但不易找到）。

## 处理优先级（维护者参考）

| 级别 | 例子 |
|---|---|
| P0 | 装了打不开、数据丢失、桌面文件找不到 |
| P1 | 热键唤不出、搜索没结果、插件点了没反应 |
| P2 | 图标模糊、文案别扭、排序不合直觉 |
