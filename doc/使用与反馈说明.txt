LyLaunch 轻快启动 · 使用说明

按一个热键弹出一个小窗口，输入拼音首字母就能打开电脑上的任意软件，
带剪贴板历史和几个小插件（翻译 / 截图 / OCR / 硬件信息 / 桌面整理）。
纯本地运行，不联网上传任何东西。

────────────────────────────────
一、安装与运行
────────────────────────────────
环境：Windows 10/11，Python 3.12+（开发环境为 3.14.7）

  1. 安装依赖：python -m pip install -r requirements.txt
  2. 启动：python main.py
  3. 快捷键默认 Alt + 空格 唤出窗口（可在设置页修改）

首次运行会在 %LocalAppData%\LyLaunch\ 建数据目录（配置、插件、日志都在这里）。
离线翻译模型、本地推理运行时不随仓库分发，首次使用对应功能时按需获取。

────────────────────────────────
二、怎么用
────────────────────────────────
· 输入 wx 再回车 → 打开微信（对应软件没装的话换别的，比如 qq）
· 输入软件名或拼音首字母 → 搜索本机应用与文件
· 打开「剪贴板历史」→ 复制几段文字 → 翻到并一键粘贴
· 打开「桌面整理」→ 试一次「收纳」，把桌面文件收进「桌面净化」文件夹
  （会真的移动文件；不想动就先别点，或点完再点「恢复原状」）
· 设置页可改热键（按下你想用的组合即可）

────────────────────────────────
三、出问题了怎么反馈（三件套）
────────────────────────────────
请通过项目仓库的 Issues 提交，尽量附上：

1. 版本信息：程序里「设置 → 关于」那一块
2. 复现步骤：点了什么 → 期望什么 → 实际看到什么（截图/录屏更好）
3. 日志文件：%LocalAppData%\LyLaunch\crash.log
   （把这一行粘到文件资源管理器的地址栏回车就能打开目录；
     没有这个文件说明是界面逻辑问题，不是崩溃）

────────────────────────────────
四、常见问题
────────────────────────────────
· SmartScreen / 杀软误报：未签名的 exe 可能被拦截或误报，属个人项目常见情况，
  可按需选择「更多信息 → 仍要运行」或对单个文件加白名单。
· 桌面被 OneDrive 重定向：收纳后文件在「桌面净化」文件夹，同步可能触发上传，请先确认。
· 卸载前先恢复：先点「恢复原状」再卸载，否则文件留在「桌面净化」文件夹里。
